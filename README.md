# astrbot_plugin_breeze_tts

AstrBot 插件：按概率把 bot 的 LLM 回复转成 [Breeze TTS 2](https://github.com/breezeblue-ai/breeze-tts) 语音。每条语音会先让模型判断这句话该用什么情绪，自动生成语气指导，并按需插入 `[笑]` `[叹气]` 等行内声音标签。

## 功能

- **按概率转语音**：可按平台、会话白名单/黑名单、发言人白名单限制生效范围
- **情绪识别**：额外调一次（建议用快的小模型）LLM，输出情绪、语气指导和带标签的原文；失败时退回表情包插件的 `&&happy&&` 标记映射
- **参考音频克隆**：填参考 wav 和对应文字后保持参考音色，情绪只作为语气指导
- **朗读清理**：去掉括号里的动作描写、emoji、链接；中文之间用空格代替标点的回复会补成逗号，避免一口气读完
- **语音单独发送**：表情包图片照常保留；发完立即删除临时文件
- 支持 `/playground` 模型切换接口的服务（如 breeze-tts-v100）可以要求只在指定模型（底模 / LoRA）上合成

## 依赖

- AstrBot v4
- 一个 Breeze TTS 2 服务（官方 `/v1/audio/speech` multipart 接口即可）

## 安装

把本仓库放进 `AstrBot/data/plugins/`，重启 AstrBot 或在面板里重载插件，然后在插件配置里填 Breeze 服务地址。

## 指令

| 指令 | 说明 |
|---|---|
| `/breeze` | 查看服务状态、本会话是否生效和会话 ID |
| `/breeze开` / `/breeze关` | 当前会话开 / 关语音（管理员） |
| `/breeze全局开` / `/breeze全局关` | 总开关（管理员） |
| `/breeze概率 0.3` | 设置转语音概率，也可写 `30%`（管理员） |
| `/breeze说 <文本>` | 带情绪分析合成一条语音（管理员） |

指令修改的配置会直接保存，不用重启。

## 推荐配置

**官方底模 + 参考音频 + 语气指导**（效果最好）：

- `ref_audio_path`：参考 wav（AstrBot 所在机器上的路径，5～10 秒、干净的单人说话）
- `ref_text`：参考音频的准确文字
- `emotion.use_instruction`：开
- `cfg_scale`：3

使用参考音频时，「固定音色描述」不生效，只发送情绪指导和固定语速要求。

## 经验和注意事项

- Breeze 没有 instruction 的模板（`tts_plain` / `ref_clone`）只接受 `cfg_scale=1`，否则返回 HTTP 500。插件在不发 instruction 时会自动改成 1。
- 只用音频和文字训练的 LoRA，一旦加上 instruction（即使同时给了参考音频）就容易丢音色。这种情况下请关掉 `emotion.use_instruction`，情绪只靠行内标签。
- 情绪驱动的语速变化听起来不自然，所以 prompt 禁止情绪分析提到语速，并在每条指导末尾固定加上「语速自然平稳，不要太快」（`speed_hint`）。
- 行内标签只允许放在句首或标点后面；实测 `[笑]` 效果最好。
- Breeze 一次只处理一条，忙时（409）会在 `busy_wait` 秒内重试。合成大约 1 倍实时，再加上情绪分析，短句一般 10 秒左右，所以 `max_len` 默认 100 字。
